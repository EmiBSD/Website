---
title: N6, the network stack, is met
description: Sockets, interfaces, routing, IPv4, IPv6, TCP, UDP and nfs now live in the safe kernel crate.
---
Milestone N6 closed on 2026-11-26, tagged
[`n6-network`]({{ site.repo }}/releases/tag/n6-network). From 2026-11-07 to 2026-11-26, in
53 merges, the network stack left the LandingZone tree for the crate the compiler refuses to
build with any `unsafe`:

- **The base:** the packet buffer (the mbuf), sockets and local (AF_UNIX) sockets, the socket
  system calls.
- **Interfaces and routing:** the interface core and its ioctls, the routing table and the
  routing socket, bpf, loopback and Ethernet.
- **IPv4 and IPv6:** addresses and multicast, ARP and neighbour discovery, the output and
  input paths, reassembly, ICMP and ICMPv6.
- **Transport:** TCP, UDP, raw sockets and divert(4).
- **nfs:** the client, the diskless boot and the server, over a radix tree that owns its
  nodes, which pf's tables and IPsec's policies now use too.

190 of the 331 system calls are handled natively, from 170 when N6 started. The whole test
suite passed on arm64, on two and on four CPUs, with the installer end to end. The comparison
with a real OpenBSD gave 153 of 156 steps equal, 3 expected differences and none unexpected,
with the nfs scenarios run for the first time. The close's runs found three real bugs and
fixed them: a network driver programming its multicast filter before its Ethernet attach, a
test racing the virtio GPU's refresh, and a probe with no loopback address.

The cost was measured on the host: nine micro-benchmarks rose more than 10 %. Each was traced
commit by commit. None comes from a change in the code it measures. Two are compiler layout
steps, one is a slow creep over the memory pools' changes, one appears only with nfs built in,
two flip between two levels from build to build, and three did not reproduce. The layout
items go to N12, the performance milestone.

45 adapter files of the network stack stay in the LandingZone tree until it is deleted at N9;
pf, IPsec and WireGuard move at N8.

Next is N7: the devices. The [Status]({{ '/status/' | relative_url }}) page has its plan.
